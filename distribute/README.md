# RunPod Oneshot Package

A standalone, third-party-agent-consumable export of the RunPod ComfyUI oneshot
system. No repo, Docker, or ComfyUI install needed — only Python 3.9+ and a
`RUNPOD_API_KEY`.

## What ships

| Path | What it is |
|---|---|
| `bin/rp_oneshot.py` | The run tool: template + override flags → submit → download. Stdlib only, no repo imports |
| `workflows/` | ComfyUI API-format workflow templates (read-only inputs to the tool) |
| `manifest.json` | Template metadata: model family, prompt/seed/size override nodes, compiled by the maintainer |
| `endpoints.json` | Template → RunPod endpoint id snapshot (regenerated by the maintainer) |
| `skills/runpod-oneshot/SKILL.md` | Agent skill: how to pick a template, craft a family-appropriate prompt, set seed/size, run |
| `README.md` | This file |

## Install

1. Copy `skills/runpod-oneshot/` into your agent's skills directory.
2. Keep `bin/`, `workflows/`, `manifest.json`, and `endpoints.json` together at the
   package root — the skill's commands reference them relative to that root.
3. Export your key: `export RUNPOD_API_KEY=...` (the tool reads this variable only).

## Smoke test

`--output DIR` is **required on every invocation** (including `--dry-run`): it is the
directory the job's outputs go to.

```bash
python3 bin/rp_oneshot.py --template unholy-sdxl \
  --prompt "masterpiece, best quality, a red apple on a wooden table, photorealistic" \
  --seed 42 --width 1024 --height 1024 --output ./output --wait
```

Expect one PNG under `<--output DIR>/<job-id>/` within ~5 minutes (first job is a cold
start).

## Regenerating

Not your concern as a consumer: the maintainer rebuilds this package with
`scripts/rp_distribute.py build` and re-ships it. If a template disappears or the
endpoint id goes stale, ask for a fresh package.
